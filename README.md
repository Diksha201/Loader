# 🚚 Loader – Goods Transportation Booking Platform (MERN Stack)

Loader is a full-stack MERN web application that allows users to book a loader/vehicle for relocation or movement of goods. The platform connects customers with available loader drivers in their area, simplifying short-distance logistics and goods transportation.

# Live :- https://loader-kzvs.vercel.app/

# ✨ Features

✅ User Authentication (Signup / Login)
✅ Book Loader Vehicle based on pickup & destination
✅ Real-time Booking Confirmation
✅ View & Manage Bookings
✅ Driver Availability Status
✅ Secure API with JWT authentication
✅ Responsive UI

# 🏗️ Tech Stack
Layer	Technology
Frontend	React + Tailwind CSS
Backend	Node.js & Express.js
Database	MongoDB
Authentication	JWT
Deployment	(Vercel / Render )

# 📌 Project Flow

User registers or logs in.

User selects pickup and drop location.

System matches available loader driver.

User confirms booking.

Driver receives booking request and delivers service.
